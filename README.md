## ✨ Tính năng nổi bật

Phần mềm được thiết kế tối giản với giao diện hiện đại (Dark Mode), hỗ trợ nhiều tab chuyên biệt cho mọi nhu cầu tự động hoá của bạn:

*   **🖱️ Auto Clicker (Tự động click chuột):**
    *   Hỗ trợ click chuột Trái, Phải, và Giữa.
    *   Tùy chỉnh khoảng thời gian click siêu chính xác tới từng **Giờ, Phút, Giây và Mili giây**.
    *   Hỗ trợ số lần lặp lại (đặt `0` để lặp vô hạn).
*   **⌨️ Key Presser (Tự động bấm phím):**
    *   Chỉ định phím bất kỳ (ví dụ: `a`, `space`, `enter`).
    *   Hẹn giờ khoảng cách giữa mỗi lần bấm cực kỳ chi tiết.
*   **🔴 Record / Playback (Ghi hình và Phát lại):**
    *   Ghi lại toàn bộ chuỗi hành động (chuột và bàn phím) của bạn.
    *   Lưu trữ chuỗi hành động và tự động phát lại (playback) với số lần lặp tuỳ chỉnh.
    *   Tích hợp phím tắt riêng biệt để bật/tắt ghi hình siêu tiện lợi.
*   **⚙️ Settings (Cài đặt linh hoạt):**
    *   Cho phép tuỳ chỉnh phím tắt Start/Stop tổng (`F8` mặc định).
    *   Cho phép tuỳ chỉnh phím tắt Bắt đầu/Dừng ghi hình riêng (`F9` mặc định).

## 🚀 Hướng dẫn cài đặt

Nếu bạn muốn chạy ứng dụng từ mã nguồn (dành cho Developer):

1. **Yêu cầu hệ thống:** Máy tính cần cài đặt sẵn Python (phiên bản 3.7 trở lên).
2. **Cài đặt thư viện:**
   Mở terminal hoặc command prompt trong thư mục dự án và chạy lệnh sau:
   ```bash
   pip install -r requirements.txt
   ```
   *(Các thư viện chính được sử dụng bao gồm: `customtkinter` cho giao diện và `pynput` để điều khiển/lắng nghe sự kiện chuột, phím).*

3. **Chạy ứng dụng:**
   ```bash
   python main.py
   ```

**Lưu ý cho người dùng thường:** 
Nếu tải bản đóng gói `.exe` (trong thư mục `dist`), bạn chỉ cần click đúp vào file `main.exe` để chạy ngay mà không cần cài đặt Python.

## 🎮 Cách sử dụng

### 1. Tab "Auto Clicker" hoặc "Key Presser"
- Nhập thông số bạn mong muốn (thời gian giãn cách, phím hoặc chuột cần click).
- Nhấn nút **Start** trên giao diện, hoặc sử dụng **Phím tắt toàn cục** (mặc định là `F8`) để bắt đầu hoặc dừng bất kỳ lúc nào.

### 2. Tab "Record / Playback"
- Để bắt đầu thu hành động, ấn nút **Start Recording** hoặc bấm phím tắt Ghi hình (mặc định là `F9`).
- Thực hiện chuỗi các thao tác bạn muốn.
- Ấn phím `F9` lần nữa để dừng thu.
- Chọn số lần phát lại mong muốn và ấn nút **Play** (hoặc `F8`) để phần mềm lặp lại thao tác cho bạn.
